Complete Step-by-Step Guide to Install V2Ray/Xray

🛠️ Step 2: Install Xray (Better than V2Ray)

✅ Summary of Main Steps:
1.	Buy server (DigitalOcean/Hetzner)
2.	Install Xray (install command)
3.	Create config file (with nano)
4.	Generate UUID and keys (two commands: cat and x25519)
5.	Start service (systemctl)
6.	Install on mobile (v2rayNG)
7.	Test (ipleak.net)
